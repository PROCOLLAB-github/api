# BE05: ответы черновика и материалы

PATCH решения сохраняет частичные ответы капитана с expected_version и expected_form_revision. Пропуск оставляет ответ, null очищает, пустой текст также удаляет запись. Неполная форма допустима; 0 и false сохраняются без преобразования. Чужие и повторные ID, неверные типы, выбор и ограничения отклоняются до записи. Программа, решение, определения и файлы блокируются в общем порядке; конфликт не сохраняет часть запроса. После срока черновик остается доступен для сохранения по прежним правилам, после сдачи и при откате режима запись запрещена.

Материалы используют существующий UserFile. Проверяются владелец/принадлежность этой заявке, размер до 100 MiB или меньшего предела поля, расширение и тип содержимого. Миграция files 0008 добавляет внутренний detected_mime_type, публичный ответ upload остается ровно {url}. Совместимый C00 1.2.0 добавляет optional query preserve_original=true: материалы сохраняют исходные байты изображения; остальные клиенты по-прежнему получают WebP. Прежняя загрузка без метаданных проверяется только на настроенном CDN без redirects, с таймаутом и ограничением прочитанных байтов. Внешний URL файлом не становится.

Очистка ответа не удаляет бинарный объект. Ссылка в сданных ответах или immutable snapshot запрещает удаление UserFile через API, admin и ORM до вызова CDN. Admin bulk сначала проверяет всю выборку. Ошибки конструктора BE04 приведены к зафиксированным кодам C00: permission_denied, template_locked и field_in_use.

Проверено тестами: 90 сценариев решения на локальном PostgreSQL, включая 20 сценариев сохранения/файлов и конкурентные PATCH с одной версией. Проверены настоящий PNG и прежний WebP, подмена MIME, права, размер, очистка, неизменность snapshot, admin bulk и legacy CDN redirect. Black/Flake8, check, makemigrations --check и валидатор C00 прошли. Полный Linux CI проверяется для опубликованного commit отдельно.

Проверено в браузере: настоящий Angular + Django/PostgreSQL/JWT, обе формы, пустой черновик и явный выбор кейса, сохранение из вкладки команды, конфликт двух вкладок с сохранением ввода, привязка и очистка PDF, байты исходного PNG, повторное открытие 0/false, 390 px без overflow и ошибок JavaScript. Только внешнее хранилище заменено локальным адаптером; HTTP upload, UserFile и PATCH работают реально.

BE06 остается следующим блоком: атомарная сдача, окончательные проверки готовности и создание снимка. Новый режим для реальных программ не включался.
