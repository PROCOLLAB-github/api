# BE04: форма решения и стартовые шаблоны

Реализованы четыре операции C00: шаблоны, чтение формы участником, чтение использования полей организатором и полный PUT конфигурации. Шаблон копируется только явным действием, GET не выбирает его автоматически. Системные название и команда не входят в конструктор.

PUT под блокировкой программы проверяет полномочия, режим, expected_revision, ID и порядок полей. Типы, назначения, обязательный case/select и ограничения проходят строгую проверку. Порядок нормализуется; новые radio не создаются, существующие читаются. Новый служебный name генерируется сервером; системный case сохраняется независимо от подписи.

Защищены непустые ответы новой сущности и прежние значения программы. Используемое поле нельзя удалить, перенести, сменить его тип или назначение; использованный вариант нельзя удалить или переименовать. Сужение ограничений проверяется по сохраненным значениям и метаданным UserFile. После ответов нельзя сменить шаблон. Новая обязательность влияет на черновики; affected_draft_count вычисляется сервером, 0 и false считаются ответами. Сданное представление остается в snapshot.

Миграция 0031 добавляет nullable JSON solution_options для вариантов без потерь, включая символ |. Старые options не переписываются и читаются прежним способом при null. Прежний project-form не записывает определения нового конструктора, включая технический откат режима. Model/admin сохраняют проверки используемых определений; новые команды формы используют единый порядок блокировок программа → поля. В ответ прежнего management добавлен совместимый solution_storage_mode для выбора нужного интерфейса.

Проверено на локальном PostgreSQL: 70 тестов основы, состава, приглашений и формы; 17 новых сценариев формы включают конкурентные PUT с одной ревизией. Отдельно прошли 130 проверок прежних кейсов/команд/приглашений и 32 проверки управления программой. При первом составлении команды один несуществующий test target дал ошибку импорта; корректный management target проверен отдельно. После ревью моделей повторены 64 проверки и 34 проверки формы/кейсов. Black, Flake8, миграция на локальной БД и контракт C00 прошли.

Настоящий Angular/JWT сценарий организатора: скопировать КЧ, добавить варианты, сохранить форму и открыть предпросмотр. Проверены серверный счетчик, отсутствие автоселекции кейса и desktop/390 px без JavaScript ошибок и overflow. Предыдущий commit BE02–BE03 55b45c0 прошел Linux PostgreSQL CI (1418 + 39 проверок); это не заменяет CI текущего BE04. Новый режим не включается для пользователей этим изменением. Ответы, файлы и реальная команда сдачи продолжаются BE05/BE06.
