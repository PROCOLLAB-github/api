Путь намеренно меняет синтетические данные: 28 mutating HTTP requests в сохраненном browser evidence, включая два ожидаемых 409. Это не число сохраненных изменений и не zero writes. Raw attempt сохранен, финальные postconditions перечитаны с явным ожиданием DELETE, повторной сдачи не было. Evidence явно объединяет завершенные фазы и resumed final verification, а не заявляет одну непрерывную успешную invocation.

Production CDN, внешние avatars и рассылка не использовались. ## GAP-A: административные исключения после сдачи

Source: management_project_actions.inspect_action/apply_action и tests/test_management_project_actions.py. Legacy организаторский путь после подписанного preview разрешает submit после срока, change_case сданной заявки, detach program link; Project и оценки сохраняются. participant_removal удаляет program link капитана, членство/приглашения и регистрацию, сохраняя исходный Project/ProjectScore. Новое решение владеет данными напрямую, отдельной Project-копии у него нет.

Противоположный инвариант: AC09 и solution_team.require_mutable/solution_models.save фиксируют ответы/капитана/состав/snapshot после submit. Прежние destructive handlers в solution mode отклоняются. Административные исключения нельзя перенести снятием этого guard или удалением owner с cascade без явного правила для сданной работы/оценок/публичных материалов.

25.10 вопрос задан пользователю: сохранить сданные заявки неизменными или сохранить административные исключения после сдачи. Ответ не получен. В этой матрице ни один вариант не выбран, новые writers не добавлялись. Поздняя первая сдача организатором — отдельный существующий сценарий; он не меняет уже сданный snapshot и может исследоваться независимо. Обычное право капитана и дедлайн не расширяются этим документом.

## GAP-B: выключение нового создания при откате

Прямое требование REL01: «при откате выключить создание новых решений, сохраняя доступ к уже созданным работам и их данным». Исходный source audit выявил отсутствие отдельного переключателя; переключение storage mode обратно в legacy_project блокировало обычные writers существующего решения.

Existing read/edit/files/team/invites/submit/evaluation/publication не отключаются; обычный stale program save не отменяет операторский флаг. 17 новых / 261 final PostgreSQL tests, 2760 frontend tests/478 files/strict types/build/lint/format, actual browser КЧ/хакатона и 30 HTTP/C00 checks PASS. Программы 9/10 и решения 8/10 submitted, 9/11 draft; final flags False. Hash всех прежних данных совпадает с baseline до rehearsal. Это не полный REL01, не rollout реальных программ и не закрытие других AC. D02/D03, административная политика и конкурсные черновики остаются отдельными gates.
