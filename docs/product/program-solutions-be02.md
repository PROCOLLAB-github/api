# BE02 — состав команды внутри решения

Продолжение утвержденных C00 1.0.0 и D00 v3, после BE01/FE01. ТЗ: https://chatgpt.com/space/page_9632e9ed74588191b6b3e4b397d55175 . База — dev 562d0727. Новый режим остается выключенным по умолчанию.

## Контракт и план

Состав читается в существующем GET решения. Реализуются три уже определенные C00 команды: DELETE `members/{user_id}/` с expected_solution_version в query; POST `leave/` с TeamCommand; POST `captain/` с CaptainCommand. Remove и transfer возвращают MutationReceipt с новой версией; leave — 204. Ни Project ID, ни отдельная Team не появляются. Ответы и ошибки сохраняют snake_case и C00 envelope. Другие команды BE03–BE06 остаются закрыты.

Все команды проверяют program/solution scope, включенный режим, конкретного капитана или собственное членство, состояние и ожидаемую версию внутри транзакции. Общая блокировка программы сериализует изменения между решениями и старым контуром; затем блокируется решение. Передача допускается только уже принятому участнику и оставляет прежнего капитана в составе. Капитан не удаляется и не выходит до передачи полномочий. Минимум не мешает выходу/удалению в черновике; сданный состав неизменяем. Дедлайн сам по себе не вводит новый запрет управления составом: существующая policy фиксирует состав после сдачи.

Общая policy регистрации, активной конкурсной exclusivity, максимума с pending резервами и минимума на сдаче применяется через владельца данных. Legacy API и его действующие model/admin проверки учитывают принятые составы новых решений. Завершенные и неконкурсные программы сохраняют прежние исключения; pending во второй команде не означает принятое участие. Новый административный интерфейс решений относится к BE08.

Проверки в scope: AC04 — вложенный состав; AC06 — полномочия капитана; AC07 — счетчики/границы policy; AC08 — сериализация конфликтующих составов, в том числе с legacy; AC09 — фиксация; AC20 — изоляция программ. Полный цикл приглашений AC05/AC08 и submit AC15 завершаются в BE03/BE06.

План реализации: общие проверки двух владельцев → сервисы команд под блокировками → C00 HTTP adapters и permissions → PostgreSQL позитивные/негативные/конкурентные тесты и legacy regression → review и PR.
