# Контракт категорий ленты

`GET /feed/?type=project|vacancy|news&limit=6&offset=0` сохраняет стандартную
пагинацию `count`, `next`, `previous`, `results` и дополнительно возвращает
`counts` — количество доступных пользователю записей во всей ленте, независимо
от текущего фильтра и страницы:

```json
{
  "counts": {
    "all": 4,
    "project": 2,
    "vacancy": 1,
    "news": 1,
    "partnerprogram": 0,
    "education": 0
  }
}
```

`project` включает новости проектов и записи о новых проектах; `news` — новости
пользователей. Черновики, закрытые проекты и неактивные вакансии не учитываются,
как и в самой ленте. Новости программ и образование пока не включены в этот
endpoint, поэтому их счётчики равны нулю. `all` — сумма доступных категорий.

Каждый элемент `results` теперь содержит `published_at` — дату публикации
записи ленты. Поле есть и у карточек новостей, и у вакансий, и у новых проектов.
При одинаковой дате сортировка дополнительно использует `id` по убыванию,
чтобы последовательность страниц была определённой.
