# Архив вакансий проекта — API

База: dev 1c424ff. Дизайн и ручные действия согласованы 21.10.2026.

- PATCH /vacancies/{id}/: is_active=false закрывает набор, отклоняет ожидающие отклики и ставит email-уведомления после commit. Повторное закрытие не меняет дату и не дублирует письма.
- PATCH с is_active=true: возобновление требует опубликованного публичного проекта, не меняет прежние решения.
- DELETE /vacancies/{id}/: наличие любого отклика запрещает удаление, включая архив. Ответ 400 содержит code=vacancy_has_responses и detail.
- Поле total_response_count readonly и включает всю историю. response_count продолжает считать ожидающие решения отклики.
- Руководитель и администратор проверяются после блокировок Project → Vacancy. Порядок совместим с операциями над откликами.
- В публичном представлении проекта закрытые вакансии скрыты; менеджер видит обе группы.
- PATCH/PUT валидируются до изменений. Invalid skills не удаляют прежние навыки; PUT без is_active не отклоняет отклики.

Миграций и новых endpoint нет. API нужно внедрять до связанного Angular PR.
