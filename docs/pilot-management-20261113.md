# Согласованное управление пилотным чемпионатом

Макеты списка критериев и общего рейтинга согласованы владельцем 13 ноября 2026 года;
редактор критерия согласован ранее. Источник: Figma PROCOLLAB UI KIT,
`tvog0fpEgWgEtr7KUTjbyE`, страница `2087:51158`.

## Поведение и контракт

- Чекбокс включает существующий режим `weighted_percent`. Веса числовых критериев
  обязательны, положительны и в сумме равны 100%. Выключенный чекбокс оставляет
  `legacy`: исходные баллы числовых критериев суммируются. Среднее завершенных
  оценок экспертов и фиксация критериев после первой сохраненной оценки сохранены.
- Общий рейтинг складывает официальный результат кейса и квиз. Например, 24 балла
  за кейс и 80 за квиз дают 104. Исходная оценка не переводится принудительно в 0–100.
  Взвешенный кейс по-прежнему имеет максимум 100. `case_maximum` и `maximum` теперь
  фактические числа либо `null`, если шкала не ограничена. API, admin и Excel
  используют один сервис. Отсутствующий результат отличается от нуля; итог и место
  появляются только после обоих завершенных этапов. Равные итоги делят место.
- Рейтинг доступен только действующим организаторам и уполномоченным сотрудникам.
  Фильтры и экспорт сохраняются. Публичного изменения баллов квиза нет.
- Только профиль пилота включает `WHITE_LABEL_ORGANIZERS_ARE_EXPERTS`. Подготовка
  добавляет активных менеджеров настроенной программы в `Expert.programs`; сигнал
  обрабатывает последующее добавление организаторов через API и admin. Глобальная
  роль пользователя, staff, участие в команде, существующие кейсы и назначения
  эксперта не меняются. Писем при назначении роли нет. Проекты автоматически не
  распределяются: используется существующее распределение и настоящий экран оценки.
- В чистой БД уведомление об оценке использует шаблон из кода. Оно отправляется после
  фиксации оценки; сбой доставки не превращает успешное сохранение в ошибку API.
  Остальные программы сохраняют прежний сценарий уведомлений.

## Интерфейс

Чекбокс, поля и кнопки используют текущий UI kit и Mont. Компактные поля веса
выровнены с кнопками: 32 px на компьютере и 44 px в мобильном представлении.
Предпросмотр формы эксперта удален. В программе пилота есть переход «Оценка проектов»
в существующий кабинет с материалами проекта и формой оценки.

Пилот фиксирован в светлой теме, включая первое открытие с сохраненной темной темой.
Пункт тем скрыт; сохраненные предпочтения не удаляются. Обычный режим продолжает
поддерживать все темы. Поиск рейтинга совпадает с поиском участников: 44 px на
компьютере, около 48,4 px и шрифт 16 px на телефоне.

## Проверка и выпуск

Проверены PostgreSQL: 262 теста расчета, прав, экспертного членства, регистрации и
оценивания. Angular: 511 файлов, 3234 теста и проверка типов контракта решений;
сборка pilot. Браузер проверил сохранение критериев, неверную сумму весов, отмену,
размеры 320/390/820/1024/1440, реальную оценку организатором, блокировку критериев,
оба расчета рейтинга и скачивание Excel. Тестовые данные вымышленные.

Выпуск предназначен только для действующего hosted-v2 пилота после общего рейтинга
`3c21fbc` / интерфейса `3241381`. Новых миграций нет. Установщик проверяет исходную
версию, сохраняет проверенную копию БД, интерфейс и конфигурацию nginx, использует
прежний Docker image и заменяет только web пилота. БД и DEV/PROD не перезапускаются.
Basic Auth снимается только с include пилота; штатные API/admin-права сохраняются.
Другие конфигурации nginx и защищенные контейнеры контролируются по fingerprints.

Откат возвращает web, интерфейс и браузерную защиту без восстановления БД поверх
новых данных. Добавленное экспертное членство сохраняется. Работа nginx и откат
проверены на отдельном локальном стенде с независимым vhost; замена и откат Docker
проверены на временных локальных контейнерах. Факт установки на сервер подтверждается
отдельно выводом `check/apply/status` и проверкой HTTPS после установки.

Исправления тем DEV из PR 542 ранее установлены и проверены отдельно. Новые функции
этого выпуска не выкладываются в DEV или PROD и не включают разработку квиза.
